# Unegui.mn — Орон сууц зарны шинэ зар хянагч

Энэ систем нь **unegui.mn** сайтын "Орон сууц зарна" ангиллын шинэ зарыг
өдөр бүр автоматаар шалгаж, вэб хуудсан дээр жагсаадаг.

## Хэрхэн ажилладаг вэ?

1. GitHub Actions гэдэг үнэгүй үйлчилгээ өдөр бүр (Улаанбаатарын цагаар өглөө 07:00 орчимд)
   `scraper/scrape.py` скриптийг ажиллуулна.
2. Скрипт unegui.mn-с зарын жагсаалтыг татаж, өмнө нь харж байгаагүй (шинэ) зарыг олно.
3. Шинэ зарыг `docs/index.html` файлд нэмнэ.
4. GitHub Pages энэ файлыг вэбсайт болгож, та утаснаасаа browser-аар үзнэ.

## Тохируулах алхмууд (нэг удаа хийнэ)

### 1. GitHub-д репозитор үүсгэх
- github.com дээр бүртгэлгүй бол бүртгүүлнэ.
- **New repository** дараад нэрийг нь жишээ нь `unegui-tracker` гэж өгнө.
- **Public** сонгоно (GitHub Pages үнэгүй ашиглахад хялбар байдаг тул).

### 2. Файлуудыг репозитор руу оруулах
- Репозитороо нээгээд **Add file → Upload files** дараад энэ багц дахь бүх
  файл, хавтасны бүтцийг хадгалж оруулна (эсвэл `git push` ашиглаж болно).

### 3. Push хийх зөвшөөрөл олгох
- Репозитор дотор **Settings → Actions → General** руу орно.
- "Workflow permissions" хэсэгт **Read and write permissions** гэдгийг сонгоод Save дарна.
  (Скрипт шинэ өгөгдлөө репозитор руу буцаан commit хийхэд энэ шаардлагатай.)

### 4. GitHub Pages асаах
- **Settings → Pages** руу орно.
- "Source": **Deploy from a branch**
- "Branch": **main**, folder: **/docs**
- Save дарна.

### 5. Нэг удаа гараар туршиж үзэх
- **Actions** таб руу орно.
- "Daily Unegui Scrape" ажлыг сонгоод **Run workflow** дарна.
- 1-2 минутын дараа ажил дуусна (ногоон ✓ гарна).

### 6. Үр дүнгээ үзэх
- Хэдэн минутын дараа дараах хэлбэрийн хаягаар нэвтэрч болно:
  `https://<GitHub хэрэглэгчийн нэр>.github.io/unegui-tracker/`
- Энэ хаягийг утасныхаа browser дээр bookmark хийвэл өдөр бүр шинэ зарыг
  шууд харах боломжтой.

## Анхаарах зүйлс

- Скрипт эхний 3 хуудсыг л шалгадаг (VIP зарууд үргэлж дээгүүр гардаг тул).
  Илүү гүнзгий шалгуулах бол `scraper/scrape.py` дотор `PAGES_TO_CHECK`
  тоог нэмж болно.
- unegui.mn сайт HTML бүтцээ өөрчилбөл (жишээ нь anti-bot хамгаалалт нэмбэл)
  скрипт зөв ажиллахгүй болж магадгүй. Ийм тохиолдолд надад хэлээрэй,
  дахин тохируулж өгье.
- Энэ нь зөвхөн хувийн хэрэглээнд зориулсан, нэг удаагийн, хэмнэлттэй
  (өдөрт нэг удаа л хандах) хандалт хийдэг тул сайтад дарамт үзүүлэхгүй.
